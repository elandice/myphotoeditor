# Luma Studio

Flutter로 만든 PC·모바일 사진 편집기입니다. Windows/macOS/Linux, Android/iOS, 웹에서 공통 편집 엔진을 사용하며 한국어 UI를 제공합니다.

## 구현 기능

포토샵에서 자주 쓰는 편집 흐름을 확장했습니다. **15개 도구**, **8개 픽셀 필터**, 선택 영역 클립보드, 레이어 마스크, 이미지 작업과 편집 가능한 프로젝트 저장을 제공합니다.

- 선택: 사각형·타원·올가미·연결된 색상 자동 선택, 전체 선택·선택 반전. 움직이는 점선은 실제 선택 경로를 따라 그립니다.
- 리터칭·색상: 스포이드, 연결된 색 영역 페인트 통, 두 색상 그라디언트, 활성 레이어 원본을 사용하는 복제 도장. PC는 Alt 클릭, 모바일은 **복제 원본 지정** 버튼으로 원본을 정합니다.
- 도형: 채운 사각형·타원 및 윤곽선. 윤곽선 두께는 브러시 크기를 사용합니다.
- 클립보드: 앱 내부 복사·잘라내기·붙여넣기·삭제. 다른 크기의 문서에 붙여넣어도 원본 픽셀 크기를 유지합니다. Ctrl/⌘ A/C/X/V, Delete를 지원합니다.
- 이미지: 선택 경계로 자르기, 이미지 크기 변경, 90° 회전, 활성 레이어 좌우·상하 반전.
- 마스크: 선택 영역에서 알파 마스크 생성, 적용 켜기/끄기, 반전, 제거. 원본 이미지는 마스크를 제거하여 다시 표시할 수 있습니다.
- 합성: 일반 블렌드 레이어끼리 아래와 병합, 보이는 레이어 전체 합성. 블렌드 모드가 배경 색상에 의존하는 경우 전체 합성을 사용하여 현재 결과를 유지합니다.
- 필터: 색상 반전, 흑백, 세피아, 가우시안 흐림, 선명하게, 포스터화, 임계값, 자동 대비. 선택 영역만 처리할 수 있으며 일부 필터는 강도·반경·단계를 설정합니다.
- 파일: **문서 메뉴 → 프로젝트 저장/열기**. `.luma`는 레이어·텍스트·마스크를 보존하는 앱 전용 JSON/PNG 형식이며 PSD 읽기/쓰기는 지원하지 않습니다. 프로젝트 저장 단축키는 Ctrl/⌘ S, 합성 이미지 내보내기는 상단 **내보내기** 버튼입니다.
- 화면: 도구 모음에서 모든 도구에 접근하고 레이어·조정·필터·기록 패널을 전환합니다. 작업 기록에는 Undo 단계와 이미지 메모리 사용량이 표시됩니다.

프로젝트 파일 한도는 128MiB, 레이어는 64개, 이미지·마스크 디코딩 메모리 합계는 256MiB입니다. 불러오기 실패 시 현재 문서는 유지됩니다. 픽셀 필터는 현재 레이어에 적용되며 Undo로 복원합니다.

- 단일 편집 뷰포트: 브러시·지우개, 브러시 크기/색상/불투명도/펜 압력, 포인터 중심 휠 줌, 화면 이동, 두 손가락 핀치·팬.
- 레이어: 개별 오프스크린 이미지, 합성 순서 변경, 추가·복제·삭제·이름 변경, 가시성·잠금·투명도. 지우개는 선택한 레이어에만 작용합니다.
- Undo/Redo: 변경한 레이어 이미지만 새로 생성하고 나머지는 공유합니다. 스트로크/슬라이더 드래그/변형 제스처를 각각 한 단계로 저장합니다. 최대 40단계, 고유 이미지 합계 128MiB를 기준으로 오래된 기록을 제거합니다. 현재 문서 자체가 예산을 넘으면 현재 레이어와 추가 이미지 메모리를 사용하지 않는 이름·속성 변경 기록을 유지합니다.
- 색상 지정: 그림판처럼 기본 색상표와 사용자 지정 색을 선택합니다. 색 편집 창에서 무지개 영역·밝기 막대·RGB·HEX로 색을 지정하고 적용 또는 취소할 수 있습니다. 사용자 지정 색은 현재 세션에서 유지됩니다.
- 작업 보호: 변경한 문서에 미저장 표시를 붙이고 새 문서·프로젝트 교체 및 앱 종료 전에 저장 여부를 확인합니다. Undo/Redo로 마지막 저장 상태에 돌아오면 미저장 표시도 복원됩니다. PNG 내보내기는 편집 가능한 프로젝트 저장을 대신하지 않습니다.
- 자동 복구: 편집이 4초 동안 멈추면 앱 전용 폴더 또는 브라우저 IndexedDB에 `.luma` 복구본을 저장합니다. 다음 실행에서 복구 여부를 선택합니다. 입력 대화상자·진행 중 획·변형·파일 작업 중에는 복구 저장을 보류합니다. 복구본은 직접 저장한 프로젝트와 별개입니다.
- 파일: PNG/JPEG/WebP/GIF/BMP 가져오기, 보이는 레이어를 합성한 투명 PNG 내보내기. 가져온 이미지는 비율을 유지해 현재 캔버스에 맞춘 새 레이어로 추가됩니다. GIF는 첫 프레임을 사용합니다.
- 선택·변형: 움직이는 점선 경계와 선택 영역 클리핑. **선택 후 V(변형)**를 사용하면 활성 레이어의 선택한 픽셀만 이동·회전·확대/축소하고 바깥 픽셀은 유지합니다. 선택 경계의 모서리는 크기, 위쪽 손잡이는 회전을 조절하며 레이어 패널 슬라이더도 같은 선택 영역에 적용됩니다. 선택이 없으면 레이어 전체를 변형합니다.
- 고급 편집: 일반/곱하기/스크린/오버레이/어둡게/밝게/차이/더하기 블렌드, 밝기·대비·채도, 편집 가능한 텍스트 레이어.
- 반응형 화면: PC 도구 레일·레이어 패널, 모바일 하단 도구·접이식 패널. 320px, 390px, 600px, 700px, 800px, 1000px, 1440px 및 가로 화면 테스트 포함.

웹은 실제 GLSL WebGL 셰이더로 정지 상태 미리보기와 PNG 합성을 처리하며 레이어를 한 장씩 업로드해 임시 래스터·RGBA 메모리가 레이어 수만큼 누적되지 않게 합니다. 픽셀 필터와 연결 영역 탐색은 Web Worker를 사용합니다. 선택 점선·커서·도구 미리보기는 문서와 별도로 그립니다. 드래그 중 즉시 그리기 및 WebGL 불가 환경은 Flutter Canvas 합성을 사용합니다. 네이티브 앱은 Flutter의 플랫폼 그래픽 백엔드와 BlendMode를 사용합니다. 자세한 설명은 [렌더링·파일 설계](docs/rendering-and-files.md)를 참고하세요.

## 실행

Flutter 3.38.9 / Dart 3.10.8에서 검증했습니다. Flutter가 PATH에 없으면 이 PC의 `C:\flutter\flutter\bin\flutter.bat`을 사용하세요.

```powershell
flutter pub get
flutter run -d chrome
```

네이티브 실행:

```powershell
flutter run -d windows
flutter run -d <android-device-id>
```

macOS/iOS 빌드는 macOS와 Xcode가 필요합니다. Windows 앱 빌드는 Visual Studio의 **Desktop development with C++** 워크로드 및 플러그인 심볼릭 링크를 위한 개발자 모드가 필요합니다. 이 작업 환경에는 Visual Studio가 없어 Windows 실행 파일을 만들지 않았습니다. OS 설정은 변경하지 않았습니다.

## 빌드와 미리보기

```powershell
flutter build web --no-pub
node scripts/serve-preview.mjs
# http://127.0.0.1:4173

flutter build apk --debug --no-pub
# build/app/outputs/flutter-apk/app-debug.apk
```

웹 빌드와 Android 디버그 APK 빌드에 성공했습니다. APK는 개발용 서명으로 생성된 테스트 설치 파일이며 스토어 배포용이 아닙니다. Android/iOS 실기기 실행 및 Windows/macOS/Linux 네이티브 실행은 별도 확인이 필요합니다.

Android 릴리스는 디버그 키를 사용하지 않습니다. `android/key.properties`에 `storeFile`, `storePassword`, `keyAlias`, `keyPassword`를 설정하거나 `LUMA_STORE_FILE`, `LUMA_STORE_PASSWORD`, `LUMA_KEY_ALIAS`, `LUMA_KEY_PASSWORD` 환경 변수를 제공합니다. 서명 설정이 없으면 직접·간접 릴리스 빌드 모두 실패합니다. 키 파일과 설정은 Git에서 제외합니다. 배포 전 앱 식별자 `com.example.myphotoeditor`도 실제 배포용으로 정해야 합니다.

## 조작

| 기능 | PC | 모바일 |
| --- | --- | --- |
| 그리기/지우기/선택/변형 | 현재 도구로 드래그 | 한 손가락 드래그 |
| 화면 확대·이동 | 휠 줌, H 또는 Space+드래그, 가운데 버튼 | 두 손가락 핀치·팬 |
| 도구 | B 브러시, E 지우개, H 이동, M 선택, V 변형, T 텍스트 | 하단 도구 |
| 실행 취소/다시 실행 | Ctrl/⌘ Z, Ctrl/⌘ Shift Z 또는 Ctrl/⌘ Y | 상단 화살표 |
| 파일 | Ctrl/⌘ O 가져오기, Ctrl/⌘ S 프로젝트 저장 | 상단/하단 파일 버튼 |
| 화면 맞춤 | Ctrl/⌘ 0 | 캔버스 우측 하단 맞춤 버튼 |
| 선택 픽셀 변형 | 영역 선택 → V → 드래그/손잡이 | 영역 선택 → 변형 → 드래그/손잡이 또는 패널 슬라이더 |
| 변형 취소/선택 해제 | 변형 중 Escape로 취소, 그 밖에는 Escape 또는 Ctrl/⌘ D로 선택 해제 | 두 손가락으로 진행 중인 변형 취소, 선택 해제 버튼 |
| 브러시 크기 | [ / ] 또는 슬라이더 | 상단 슬라이더 |

두 번째 손가락이 닿으면 진행 중인 획/변형을 취소하여 확대 동작이 그림에 남지 않게 합니다. 선택은 문서 좌표, 레이어 변형은 문서 중심 기준으로 적용합니다.

## 검증

```powershell
flutter analyze --no-pub
flutter test --no-pub
node scripts/test-web.mjs
node scripts/test-pixel-worker.mjs
node scripts/test-recovery-storage.mjs
```

Flutter 회귀 테스트는 브러시·지우개 픽셀, Undo/Redo와 저장 상태, 메모리 예산, 선택·변형, 모든 필터, 파일 저장/취소/실패, 입력 경합, 자동 복구와 반응형 화면을 검증합니다. 브라우저 검증기는 Node 22 이상과 Chrome/Chromium이 필요하며, 경로를 찾지 못하면 `CHROME_BIN`을 설정합니다. WebGL 합성 1,820개 픽셀 검증, 실제 Worker 61개 검증, IndexedDB 복구 검증 및 네이티브 Dart와 Worker 알고리즘 21개 비교를 제공합니다. `.github/workflows/verify.yml`에서 포맷·분석·회귀·브라우저 테스트와 웹·Android 디버그 빌드를 자동 실행합니다.

## 현재 범위

- 레이어·텍스트·변형·색상 보정·마스크는 `.luma` 프로젝트로 저장하고 다시 편집할 수 있습니다. 레이어 이름은 UTF-16 기준 500자, 텍스트는 100,000자까지이며 편집·저장·복원에 같은 제약을 적용합니다. 세션 Undo 기록은 복구본과 프로젝트에 포함하지 않습니다.
- 자동 복구 저장이 실패하면 직접 저장하도록 안내합니다. 브라우저는 다운로드를 실제로 보관했는지 확인할 수 없어 다운로드 시작 뒤에도 미저장 보호와 복구본을 유지합니다. 비공개 모드·저장소 삭제·OS 강제 종료·마지막 4초 내 변경이나 미확정 획·변형은 복구를 보장하지 않습니다.
- PNG는 합성된 이미지입니다. 레이어 데이터가 포함되지 않습니다.
- 텍스트 레이어에 픽셀 도구·필터를 적용하거나 문서를 자르기/회전/크기 변경하면 해당 내용을 이미지에 반영합니다. Undo로 기존 텍스트·변형·마스크를 복원할 수 있습니다.
- 선택 픽셀 변형을 적용하면 해당 레이어의 텍스트·기존 위치/회전/크기·켜진 마스크를 이미지에 반영합니다. 밝기·대비·채도·투명도·블렌드 모드는 유지합니다. 한 번의 변형을 Undo하면 원래 이미지와 선택 영역, 텍스트·변형·마스크를 복원합니다.
- 문서 한 변은 최대 4096px입니다. 큰 문서와 많은 레이어는 특히 모바일에서 메모리를 많이 사용합니다. 가져온 원본은 최대 한 변 4096px로 디코딩한 뒤 문서 크기에 맞춥니다.
- 최초 실행은 1200×900px 투명 캔버스와 바로 그릴 수 있는 빈 레이어 하나로 시작합니다. 기기에 이전 작업의 복구본이 있으면 기존 복구 안내를 표시합니다. 문서 메뉴에서 캔버스 크기를 바꾼 새 작업도 만들 수 있습니다.

## 코드 구조

- `lib/editor/editor_controller.dart`: 오프스크린 래스터, 이력, 선택, 합성, 변형, 텍스트.
- `lib/editor/editor_viewport.dart`: 마우스/터치/트랙패드 입력, 화면 좌표, 경계선과 손잡이.
- `lib/editor/editor_transform.dart`: 선택 픽셀 분리·실시간 변형 미리보기·한 번의 래스터 적용.
- `lib/editor/editor_screen.dart`: 반응형 UI, 패널, 단축키, 다이얼로그.
- `lib/services/editor_files.dart`: 시스템 파일 선택·저장 및 브라우저 다운로드.
- `lib/services/gpu_compositor*.dart`, `web/editor_blend.js`: 조건부 WebGL 브리지·셰이더.
