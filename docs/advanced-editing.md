# 확장 편집 동작

## 선택과 좌표

선택은 문서 좌표의 `Path`이며 사각형 경계는 UI 정보와 자르기에 사용합니다. 브러시·지우개·복제 도장은 선택 경로를 활성 레이어의 역변형으로 바꿔 클리핑합니다. 도형·채우기·그라디언트는 문서 좌표에서 생성하고 역변형해 레이어 픽셀에 적용합니다. 필터는 변형·색상 보정·마스크를 반영한 레이어에 처리됩니다.

선택 영역이 있으면 변형은 활성 레이어의 실제 선택 경로 안의 픽셀에만 작용합니다. 원본 영역을 잘라낸 뒤 선택 경계 중심을 기준으로 이동·회전·균일 확대/축소하며, 선택 경로와 점선도 같은 행렬로 이동합니다. 사각형·타원·올가미·자동 선택·반전 선택 모두 같은 경로 처리를 사용합니다. 선택이 없으면 기존 레이어 전체의 편집 가능한 위치/회전/크기를 변경합니다.

변형 중에는 원본 레이어 이미지와 선택 경로를 공유해 Canvas에 미리보기만 그립니다. 놓았을 때 한 번만 래스터하여 `선택 영역 변형` Undo 단계로 저장합니다. 활성 레이어의 기존 위치/회전/크기, 텍스트, 켜진 마스크는 문서 좌표의 이미지에 적용하고 색상 보정·투명도·블렌드 모드는 별도로 유지합니다. 꺼진 마스크는 같은 좌표 변형을 적용한 별도 마스크로 보존합니다. Undo는 이 변경과 선택 경로를 함께 복원합니다.

두 번째 손가락·포인터 취소·Escape는 진행 중인 변형을 되돌립니다. 레이어/도구/선택을 바꾸거나 다른 픽셀 작업을 시작할 때도 미완료 변형을 취소하여 이전 입력이 새 대상으로 이어지지 않게 합니다. PNG·프로젝트 내보내기는 표시 중인 변형을 먼저 적용합니다. GPU 합성 캐시는 미리보기 중 사용하지 않고 적용/취소 후 다시 계산합니다.

자동 선택과 페인트 통은 보이는 합성 이미지의 연결된 색상 영역을 기준으로 합니다. RGBA 채널의 최대 차이와 허용 오차를 비교하고, 투명한 픽셀은 색상 값보다 알파로 판단합니다. Scanline flood 알고리즘을 사용하며 인접 스캔라인을 합쳐 선택 경계를 단순화합니다. 비슷한 색이라도 떨어진 영역은 선택되지 않습니다.

복제 도장은 활성 레이어의 스트로크 시작 시 원본 이미지에서 샘플링합니다. 원본 위치와 획 시작 위치의 차이를 유지하며 변형된 레이어에서도 같은 문서 좌표를 사용합니다. 변경 중인 결과를 다시 샘플링하지 않아 획의 번짐이 발생하지 않습니다.

## 이력과 비동기 편집

레이어·마스크 이미지 핸들은 변경하지 않은 상태 사이에서 공유합니다. 복사한 이미지는 앱 내부 클립보드가 참조하는 동안 보존합니다. 크기 변경·자르기·회전·필터는 한 단계의 Undo로 이전 문서/레이어로 복원됩니다.

GPU 래스터 및 필터 계산 중 레이어와 선택을 바꾸는 입력을 차단하여 잘라내기나 채우기가 다른 대상으로 이동하지 않게 합니다. 실패하거나 취소한 작업은 기존 이미지를 유지하며 처리 상태를 해제합니다. 두 손가락 핀치에는 선택 경로와 진행 중인 편집을 복원합니다.

레이어 두 개를 일반 합성으로 병합할 때는 두 레이어 모두 일반 블렌드여야 합니다. Multiply처럼 아래 배경에 의존하는 모드는 쌍만 따로 합성하면 결과가 달라질 수 있으므로 전체 보이는 레이어를 합성하는 작업을 사용합니다. 전체 합성은 투명도를 유지하고 숨긴 레이어는 제외합니다.

## 프로젝트

`.luma` 버전 1은 JSON과 각 레이어/마스크의 PNG 데이터를 담습니다. 문서 크기, 레이어 순서·이름·가시성·잠금·투명도·블렌드 모드, 위치/회전/크기, 밝기/대비/채도, 텍스트/폰트/색상/위치와 마스크 적용 상태를 저장합니다. 선택과 클립보드·Undo 기록은 세션 상태입니다.

열 때 스키마, 유한 숫자와 값 범위, 지원 블렌드, 크기/개수/메모리 및 실제 이미지 크기를 검증합니다. 모든 이미지의 디코딩과 검증을 마친 후 한 번에 적용하며 실패 시 임시 이미지를 해제합니다. 저장 한도와 읽기 한도는 같게 적용합니다.
